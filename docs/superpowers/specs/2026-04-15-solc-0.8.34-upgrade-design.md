# solc 0.8.34 Upgrade — Design

**Date:** 2026-04-15
**Branch target:** `feat-cld/solc-0.8.34-upgrade` (from `liqufi-orderbook`)
**Author:** Alex + Claude

## Summary

Unify the entire `synthetix-v3` monorepo on a single Solidity toolchain:

- **Compiler:** `solc 0.8.34` (latest stable as of April 2026)
- **EVM target:** `prague`
- **Optimizer:** `enabled`, `runs: 200` (except `markets/perps-market` Foundry which keeps `runs: 10_000`)
- **Pragma style:** `pragma solidity >=0.8.11 <0.9.0` everywhere

Removes the existing `lockedConfig` override for `Proxy.sol` / `CoreModule.sol` — accepted that all proxies require full redeploy. No production migration plan is part of this spec; deployment is tracked separately.

## Motivation

Current state is a zoo: Hardhat pkgs on `0.8.17` / `0.8.22`, Foundry pkgs on `0.8.17` / `0.8.20` / `0.8.27` / `0.8.29`, `solc` npm dep pinned at `0.8.21`. No `evmVersion` explicitly set in Hardhat configs (defaults drift by compiler version). Unifying on one version per target simplifies reasoning about bytecode, gas costs, and storage layout, and unlocks Prague-era opcodes (`tstore`/`tload`/`mcopy`, EIP-7702).

## Pre-verified facts

- **MegaETH Rex hardfork** is based on Optimism Isthmus → Ethereum Prague. All cancun + prague opcodes supported. ([source](https://docs.megaeth.com/megaevm))
- **solc 0.8.34** is latest stable (npm, published ~Feb 2026). ([source](https://www.npmjs.com/package/solc))
- Base mainnet, Optimism, Arbitrum, Ethereum mainnet all activated Prague by Q4 2025.

## Target Configuration

### Hardhat (`utils/common-config/hardhat.config.ts`)

```ts
const compilerConfig = {
  version: '0.8.34',
  settings: {
    optimizer: { enabled: true, runs: 200 },
    evmVersion: 'prague',
  },
};

solidity: {
  compilers: [compilerConfig],
  // overrides removed — lockedConfig no longer applies to Proxy/CoreModule
}
```

Package-level configs (`protocol/synthetix/hardhat.config.ts`, `protocol/governance/hardhat.config.ts`) drop their own `version: '0.8.17'` override and inherit from common-config.

### Foundry

Applied uniformly in every `foundry.toml`:

```toml
solc = "0.8.34"
evm_version = "prague"
auto_detect_solc = false
optimizer = true
optimizer_runs = 200  # except perps-market: 10_000
```

Affects: `markets/perps-market`, `markets/treasury-market`, `auxiliary/Faucet`, `auxiliary/TrustedMulticallForwarder`.

### npm solc dep

`utils/core-utils/package.json`: `"solc": "0.8.34"`.

### Pragma policy

- `pragma solidity >=0.8.11 <0.9.0` — keep as is (already compatible)
- `^0.8.0`, `^0.8.4`, `^0.8.13` — keep as is (compatible)
- `^0.8.20`, `^0.8.21`, `^0.8.29` — **normalize to `>=0.8.11 <0.9.0`** to eliminate floor zoo

### CLAUDE.md update

Replace:
> Solidity 0.8.17–0.8.29 depending on package (common default: 0.8.22, optimizer 200 runs)

With:
> Solidity 0.8.34 uniform, evmVersion: prague, optimizer 200 runs (10_000 for perps-market)

## Migration Order (layered, bottom-up)

| Step | Package(s) | Changes |
|---|---|---|
| 1 | `utils/core-utils` | Bump `solc` npm dep → `0.8.34`; fixture `hardhat.config.ts` → `0.8.34` |
| 2 | `utils/hardhat-storage` | Verify plugin compatibility with solc 0.8.34 (storage:dump / storage:verify output) |
| 3 | `utils/common-config` | `version: '0.8.34'`, `evmVersion: 'prague'`, **remove `lockedConfig` override** |
| 4 | `utils/core-contracts`, `utils/core-modules` | Rebuild (config inherited), regenerate `storage.dump.json` |
| 5 | `protocol/oracle-manager` | Rebuild |
| 6 | `protocol/synthetix` | Remove local override `version: '0.8.17'` in `hardhat.config.ts`; regenerate storage dump |
| 7 | `protocol/governance` | Remove local override `version: '0.8.17'` |
| 8 | `markets/spot-market`, `markets/bfp-market` | Rebuild, regenerate storage dump |
| 9 | `markets/perps-market` | Hardhat config + `foundry.toml` (0.8.29 → 0.8.34, evm shanghai → prague) |
| 10 | `markets/treasury-market` | `foundry.toml` (0.8.27 → 0.8.34, evm → prague) |
| 11 | `auxiliary/Faucet`, `auxiliary/TrustedMulticallForwarder` | `foundry.toml` bump |
| 12 | Remaining `auxiliary/*` (RewardsDistributor, RewardsDistributorExternal, etc.) | Hardhat rebuild (inherited via common-config) |
| 13 | **Pragma sweep** | Normalize all `^0.8.20` / `^0.8.21` / `^0.8.29` in `.sol` files to `>=0.8.11 <0.9.0` |

Each step is a separate commit named `chore(<pkg>): bump solc to 0.8.34`. Final pragma sweep commit: `chore: normalize pragma directives to >=0.8.11 <0.9.0`.

## Per-step validation

Standard cycle after each step's changes:

```bash
# Build
yarn workspace @synthetixio/<pkg> build

# Storage check (Hardhat contract packages)
yarn workspace @synthetixio/<pkg> hardhat storage:dump
yarn workspace @synthetixio/<pkg> hardhat storage:verify

# Tests
yarn workspace @synthetixio/<pkg> test   # or: forge test --root <pkg-path>

# Cannon build
CANNON_REGISTRY_PRIORITY=local yarn workspace @synthetixio/<pkg> cannon:build

# Lint
yarn workspace @synthetixio/<pkg> lint
```

### Gates

- Build, tests, cannon build all green before commit.
- `storage.dump.json` diff: only metadata hash changes tolerated; **slot layout changes halt the migration** for investigation.
- Gas report: baseline captured before step 1. Final diff allowed ±15%; >50% triggers review.

### Special-case steps

- **Step 3:** after removing `lockedConfig`, confirm `Proxy.sol` and `CoreModule.sol` still compile and bytecode size stays under EIP-170 limit with `optimizer: true, runs: 200`.
- **Step 9:** `perps-market` has both Hardhat and Foundry builds — run both test suites.
- **Step 13:** text-only pragma replacement, but requires full-repo `yarn build && yarn test`.

### Final gate

```bash
yarn build    # topological
yarn test     # parallel
yarn lint
```

## Risks & Mitigations

| # | Risk | Mitigation |
|---|---|---|
| R1 | `storage.dump.json` bound to old solc metadata; metadata hash shifts on bump | Regenerate dumps after rebuild. Verify slot layout unchanged; only metadata diff is acceptable |
| R2 | All proxies require redeploy (new Proxy/CoreModule bytecode) | Accepted. Production redeploy + state/subgraph migration tracked in a separate release spec |
| R3 | Cannon registry artifacts diverge from local builds | `CANNON_REGISTRY_PRIORITY=local` for dev/test; new semver bump for publishing post-merge |
| R4 | Hardhat/cannon plugins may not support solc 0.8.34 | Step 2 explicitly verifies `@synthetixio/hardhat-storage`. Fallback: 0.8.33 or 0.8.32 if plugin breaks |
| R5 | Anvil forks need Prague support | Foundry Anvil supports Prague since ~2024 Q4. Pin minimum Foundry version or pass `--hardfork prague` explicitly |
| R6 | 0.8.22+ unchecked-loop-increment optimization alters gas even for unchanged source | Gas report diff across all tests. Expected, not blocking unless >50% |
| R7 | OpenZeppelin pragma compatibility | Both OZ 4.x and 5.x compatible with 0.8.34. Verify no dependency pins conflict |
| R8 | `push0` (shanghai) unsupported on exotic L2s | All target networks (Base, Optimism, Arbitrum, Mainnet, MegaETH) support it. Non-issue for current scope |
| R9 | `perps-market` Foundry shanghai → prague may shift gas estimations | Accept gas report diff after forge test run |
| R10 | `block_timestamp = 1_738_368_000` in perps-market foundry.toml | Unrelated to solc upgrade, do not touch |

## Out of Scope

- Deploying new proxies to production networks (Base mainnet, Arbitrum, Optimism, Ethereum L1)
- State/subgraph migration for redeployed proxies
- Publishing new Cannon registry versions of `@synthetixio/*` packages
- Updating `synthetix-deployments` repo (separate repo, separate PR)
- Any changes to `monorepo/`, `kwenta/`, `keepers*/` — they consume built artifacts and will pick up new ABIs naturally after the publish step
